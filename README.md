# Plan Pal

Build a web app for students that turns assignment screenshots into actionable plans.

Features:
- Upload image (assignment, syllabus, instructions)
- Extract text using OCR
- Automatically identify tasks, deadlines, and requirements
- Break tasks into step-by-step checklist
- Generate a timeline based on deadline

UI:
- Minimal, clean, student-friendly
- Show extracted tasks in cards
- Highlight urgency levels (low, medium, high)

Extra:
- Add a “Start Now” button for each task
- Add estimated time per task
